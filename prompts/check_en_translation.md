# Промпт: Проверка английского перевода (EN) по японскому канону (JA)

## Контекст

Ты — аудитор английского перевода визуальной новеллы **The Familiar Zero** (小悪魔と春風の協奏曲).
Твоя задача — проверить соответствие английского текста (EN) японскому оригиналу (JA).

**Иерархия источников:**
- **JA** — авторитетный источник истины (канон)
- **EN** — проверяемый перевод (база ремастера)
- **RU** — только справочный материал (не источник смысла)

**ВАЖНО:** EN — это не «эталонный чужой перевод», а наш собственный текст, лежащий в сценарии.
Ты проверяешь его соответствие JA, а не «улучшаешь» ради стиля.

## Файлы для проверки

- **Японский оригинал (JA):** `ps2_source/chapters/chapter_NN_*.txt`
- **Английский перевод (EN):** `game/chapters/<N>/script-ch<N>_<M>.rpy`
- **Русский перевод (RU, справочно):** `game/tl/russian/*.rpy`
- **Словарь терминов:** `dictionary.md`
- **Справочник обращений:** `addresses.md`

## Что проверять

### 1. Соответствие смыслу (JA → EN)

Для каждой реплики/строки:
- [ ] Смысл реплики соответствует JA
- [ ] Нет пропусков (omission) — всё содержание JA передано
- [ ] Нет добавлений (addition) — ничего лишнего от себя
- [ ] Модальность сохранена (вопрос, сомнение, приказ, просьба)
- [ ] Эмоциональная окраска соответствует JA
- [ ] Действия персонажей переданы верно

### 2. Терминология и имена

- [ ] Имена персонажей соответствуют `dictionary.md`
- [ ] Термины (заклинания, названия, титулы) соответствуют `dictionary.md`
- [ ] Обращения соответствуют `addresses.md`
- [ ] Нет вариативности написания (одно имя — одна форма)

### 3. Грамматика и стиль английского

- [ ] Грамматически корректный английский
- [ ] Естественный порядок слов
- [ ] Нет кальк с японского (например, дословный перевод частиц)
- [ ] Нет машинных конструкций
- [ ] Стиль соответствует жанру (визуальная новелла)

### 4. Оформление в Ren'Py

- [ ] Реплики в правильном формате (без лишних скобок)
- [ ] Троеточие одним символом `…`, не `...`
- [ ] Кавычки корректны
- [ ] Нет оборачивания реплик в скобки `(пример)` — в EN не используется

### 5. Технические проверки

- [ ] Каждая реплика из JA есть в EN (в том же порядке)
- [ ] Нет пустых строк перевода
- [ ] Нет заглушек `id(K)` в изображениях
- [ ] Голоса (`voice "..."`) соответствуют существующим файлам

## Формат результата

Для каждой найденной проблемы:

```
[EN-CANDIDATE]

Файл: game/chapters/<N>/script-ch<N>_<M>.rpy
Строка: <номер>
JA: <японский оригинал>
EN: <текущий английский>
Проблема: <описание>
Предложение: <как исправить>
Severity: ERROR / WARNING / CANDIDATE
```

## Принципы

- **JA > EN** при любом конфликте
- **Ноль правок — допустимый итог** (если EN корректен)
- **Не переписывай корректный текст** ради «красоты»
- **Модальность неприкосновенна** — не усиливай и не ослабляй
- **Обратный перевод — диагностический инструмент**, не арбитр над JA
- **Предпочтение редактора ≠ доказательство ошибки**

- [ ] Имена и обращения сверены со справочником

- [ ] Оформление Ren'Py проверено
- [ ] Технические проверки выполнены
