補足 / Notes on the grouping
--------------------------------------------------------------------------------
  * CH00 はエンジン実装（scene 0-3 がライブラリ）とメニュー群
    （1861-1869 = 章選択/TNDLテスト、1915-1920 = 映像ギャラリー）。
    台詞はほぼ無し。

  * シーン 62 の dateItem(...)+date(...) が「デート選択」。
    1009-1532 のデートイベント・分岐は、それを提示した章に属する。

  * CH90/91（シーン 1533-1860）は静的な参照が一切無い。
    scene 3 の getTunDeleScene() が
        (tun ? tnEventId : dlEventId) + 2 + no*3 + event[no]
    でシーン番号を計算して動的ジャンプする、トゥンデレ／デレ特殊イベント。
    dlEventId 側 = 1533 系（18 ルート×8シーン）、
    tnEventId 側 = 1697 系（同上）。
    主本編と音声 ID・台詞とも 97% 以上が重複しない別内容。

  * タイトル「魅惑のお姫さま」「小悪魔のおしおき」は
    429 / 769 がタイトルカード単体で、本編は 430 / 770。


ファイル書式 / File formats
--------------------------------------------------------------------------------
  chapters/*.txt  … 1 行 = 1 つの台詞または 1 つのイベント（源順）

      ---- SCENE 0005 ----
        [TITLE title("プロローグ")]
        [BG       stage    image=+60, level=200]
        [BGM      bgm      play=+24]
        [TRANS    trans("crossfade", 1000)]
      兵士Ａ：どこで爆発だ！  [voice 4283]
        [SPRITE   lay15    hide]
        【選択肢】シエスタ → scene 1014
        【デート】ルイズ → scene 1009
        → next scene 68

      レイヤー種別:
        BG        stage  … 背景
        EVENT_CG  event  … イベント CG
        SPRITE    lay1..lay40 … キャラ立ち絵
        BGM       bgm    … 音楽
        SE        se0..se3 … 効果音
      image=+N   → リソース ID (0x02000000 + N)
      play=+N    → 音声 ID    (0x03000000 + N)
      [voice N]  → セリフ音声 (0x04000000 + N)

  events_full/*.txt … 全呼び出しを源順で生の引数付きで列挙。
      DIALOGUE   talk(...)
      SET        set("lay5", {...})
      TRANS      trans("crossfade", 1000)
      GOTO       next((0x01000000 +12), true)
      CHOICE     selectItem("はい", (0x01000000 +7), null, true)
      DATE       dateItem("ルイズ", (0x01000000 +1009))
      TITLE / WAIT / MSGON / MSGOFF / BACK / RESET / LIKE / ITEM / MOVIE ...

  scripts/*.txt … 復元済みの生スクリプト。既定の文字コードは CP932。


シーン参照コード / Reference codes
--------------------------------------------------------------------------------
  (0x01000000 +N)  … シーン番号
  (0x02000000 +N)  … 画像（背景・立ち絵・CG）
  (0x03000000 +N)  … 音声（BGM / SE）
  (0x04000000 +N)  … セリフボイス

  シーン遷移: next() / selectItem() / moveItem() / dateItem() / date()


既知の制約 / Known limitations
--------------------------------------------------------------------------------
  * シーン 1239 はアーカイブに存在しない（0-1920 の連番で 1 つ欠番、
    実ファイル 1920 件）。
  * 12 ファイルに NUL バイトあり（quickbms 系の旧展開で欠損）。
    いずれも 26-293 バイトの極小スタブで、**talk() は 0 件 = 台詞欠損なし**。
      EMBEDDED-NUL : 1533, 1697, 1904, 1909, 1914
      trailing-only : 664, 1534, 1664, 1698, 1918, 1919, 1920
    （record 単位の圧縮形式は未解明だが、対象が極小スタブのため停止）
  * 記録単位の圧縮方式は解明済み:
        k = ZIP バイト数列へ deinterleave
            chunk = [n//k]*(k-1) + [n-(n//k)*(k-1)]   （端数は最後のチャンク）
        それをラウンドロビンで再マージ
      → 1920 件すべて文字化け率 0.0000 で復元（reconstruct_final.py）。
