# Отчёт: Pipeline проверок порта части/главы (ZnT1)

Дата: 2026-10-07
Статус: реализовано и проверено на главе 2 + по проекту целиком.

## Цель

Проверяемый, пошаговый pipeline контроля переноса чанков/целых глав сценария PS2 в
Ren'Py-ремастер: механические линт-скрипты, промпты ревью EN/RU-переводов по JA, сверка
ассетов и справочников id, оркестратор с отображением фаз (по образцу
`D:\skills\NovelEdit\noverl\tools\agent_workflow.py`). Глава может быть неполной, но
проверяемой; повторные прогоны кэшируются (MD5-детект изменений).

## Что реализовано

### 1. Механические проверки (`tools/`)

| Скрипт | Назначение | Ключевые проверки |
|--------|------------|-------------------|
| `check_renpy_syntax.py` | Синтаксис Ren'Py | баланс кавычек/скобок, отступы, `voice "…"`, `scene/show/hide/with`, обязательные конструкции |
| `check_typography.py` | Типографика | `…` вместо `...` (EN/RU), «ёлочки» в RU (не `"`) , нет обёртки реплик в `(…)` (EN/RU), пробелы у знаков препинания |
| `check_placeholders.py` | Заглушки | `id(K)` в картинках, `TODO/FIXME/XXX`, пустые `new ""`, незаполненные `filename` в `image_id_map.csv` |
| `check_assets.py` | Ассеты | существование `.ogg` голосов / файлов музыки и картинок, статистика по `image_id_map.csv`, голоса против очереди `transcriptions_ja_ru.csv` |
| `check_voice_transcriptions.py` | Озвучка | пары `voice_name ↔ voice_id` из манифеста, строки очереди CSV (помечено/не помечено), id-статистика |
| `output_util.py` | Общий вывод | `ensure_safe_output` (cp1251 — печать не падает), `print_items` (лимит 20 на коллекцию), `normalize_severity` |

Общий интерфейс: `--chapter N` (нет аргумента = весь проект), `--no-report`,
`--verbose`; полные результаты — UTF-8 отчёты `reports/check_*.md`
(типографика по главам — `check_typography_{ru,en}_ch<N>.md`).

### 2. Промпты ревью переводов (`prompts/`)

| Промпт | Назначение |
|--------|------------|
| `check_en_translation.md` | ревью EN-базы сценария по JA-канону (`ps2_source/`), пары JA → EN, модальность |
| `check_ru_translation.md` | ревью RU (`tl/russian`) по JA-канону с применением скиллов `russian-*` и правил прозы |

### 3. Оркестратор (`tools/chapter_pipeline.py`)

- 9 фаз: синтаксис → типографика RU → типографика EN → заглушки → ассеты → голоса →
  ревью EN (ручная) → ревью RU (ручная) → итоговая сводка.
- Галочки `[x]`/`[!]`/`[>]`/`[ ]` + сообщение фазы; `--status`, `--reset`, `--phase`,
  `--chapter`.
- Кэш: `reports/pipeline_state.json` (состояние фаз + MD5 всех `.rpy` главы).
  Файлы изменились → `[!] Файлы главы изменились…` и перепрогон механических фаз;
  не менялись → «Пропуск: … (уже выполнено)».
- Фазы перевода — ручные: в интерактивном терминале ждут Enter (→ `done`), в
  неинтерактивном остаются `pending` и не блокируют остальное.
- Дочерние скрипты запускаются с `PYTHONIOENCODING=utf-8`; stdout фазы (обрезанный до
  8000 символов) сохраняется в state для просмотра деталей.

## Запуск

```powershell
# Полный pipeline по главе 2 (статусы + сводки)
python tools/chapter_pipeline.py --chapter 2
python tools/chapter_pipeline.py --chapter 2 --status   # только статус фаз
python tools/chapter_pipeline.py --chapter 2 --reset    # сбросить кэш главы

# Отдельные проверки
python tools/check_renpy_syntax.py --chapter 2
python tools/check_typography.py --chapter 2 --lang ru   # ru|en|ja
python tools/check_placeholders.py --chapter 2
python tools/check_assets.py --chapter 2
python tools/check_voice_transcriptions.py --chapter 2
```

Правка файла главы → запуск показывает `[!] Файлы главы изменились…` и перепрогоняет

## Находки (переданы в `reports/log.md`, 07.10.2026)

1. **ELLIPSIS-политика** (`...` vs `…`): проверка — ERROR по ТЗ; существующий текст
   (включая эталонные главы 0/1) написан преимущественно с `...` — массовая замена
   требует явного решения человека (`???/USER DECISION`).
2. **ID_UNKNOWN**: `filename` пуст в `image_id_map.csv` для id 109, 208, 247, 269 (глава 2)
   и 114 (глава 3); в скриптах корректно стоят заглушки `id(K)`.
3. **Голоса глав 0/1/extra не в манифесте** `voice_id_map.csv` (1377 пар = ч.2+ч.3);
   `.ogg` на диске есть — бэкфилл по решению человека.
4. **103 строки `transcriptions_ja_ru.csv` части 1 главы 2 не помечены** (подтверждение
   OPEN из `reports/ch2/2.md`); способ пометки — как в частях 2–8.

## Соглашения

- PowerShell cp1251: консоль печатает только ASCII-сводку (мохибаке неизбежен), детали —
  в UTF-8 отчётах; команды с кириллицей/японским передаются только путём к файлу.
- Скрипты не меняют исходники/`tl` — только читают и пишут отчёты.
- Read-only `tl/*/common.rpy` исключён из типографики и заглушек (как в `check_project.py`).
- Типографика RU скоупится по главе через пары `old`/`new` (old из `game/chapters/<N>/`),
  поэтому неполные главы проверяются без ложных срабатываний на чужой текст.
