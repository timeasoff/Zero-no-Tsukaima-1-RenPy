## FIX — подтверждённая runtime-ошибка В ЗОНЕ
 warp `game/chapters/22/script-ch22.rpy:4` в копии дал:

```
File "game/chapters/22/script-ch22.rpy", line 6:
    $ show_sprites()
TypeError: show_sprites() missing 1 required positional argument: 'chars'
```

- **JA/EN здесь ни при чём** — это техническая сигнатура API.
- `game/scripts/features/show_sprites.rpy:420`: `def show_sprites(chars, ...)` — аргумент обязателен.
- Там же, строка 443: `if chars is None:` → «Полное снятие всех спрайтов» — то есть
  правильный вызов очистки — `show_sprites(None)`.
- Эталон проекта: `game/chapters/2/script-ch2_1.rpy` использует `show_sprites(None)`.
- Распространение: **24 вызова** (по одному в начале каждой части 22–28).

**Решение:** classification `ERROR` (runtime, TypeError) → disposition `FIXED`.
Все 24 вызова `$ show_sprites()` заменены на `$ show_sprites(None)` в
`game/chapters/22/…28/*.rpy`. Файлы `ps2_source`, JA `new`, общие TL-файлы не тронуты.
