### Методика сопоставления (S1)

Якорь события: `like` → ближайший `$ update_sympathy` той же ветки; иначе —
ближайшая озвученная talk → имя голоса через `references/voice_id_map.csv` →
строка `voice "…"` в `.rpy` → вставка после диалога (с пропуском промежуточных
безголосых gap-реплик, чтобы сохранить позицию события в источнике). Фолбэки:
сегмент сцены `# ==== SCENE N ====`, сужение по файлам сцены, соседство
stale-комментария. `tndl(null)` → сразу после `label chN`. Паринг stale:
pass1 ≤12 строк с тем же значением, pass2 ≤30 строк.

## 3. Стиль вставки (по эталону главы 1)

* `$ tndl(±30)` — отдельной строкой **сразу после** `$ update_sympathy(...)`
  либо после якорной `voice`-реплики в той же ветке/мени (индент — как у якоря);
* `$ tndl(None)` — первая строка после `label chN`
  (ch0:2, ch1:25, ch2:4, ch3:5, ch4:17, ch5:41);
* применение: `reports/tasks/T20261031-154035-97bf/s2_apply.py` — валидация
  содержимого якоря по `anchor_type` (label/syn/dialogue/stmt), отказ и незапись
  файла при конфликте, обработка файлов в обратном порядке номеров строк
  (удаление строкой > якоря не сдвигает якорь).
